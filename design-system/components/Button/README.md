Square buttons in two weights of emphasis, plus an underlined text link.

Provide the label as a lowercase verb. Use the primary fill for the single main action on a screen, the outline for everything else, and the text link for navigation to a list. Padding is 14px by 20px, border is `border-strong`, radius is `radius-none`.

| Do | Don't |
| --- | --- |
| One primary button per view | Two primary buttons side by side |
| Label with a verb: "get in touch" | Label with "submit" or "click here" |
| Keep the 2px `ink` focus outline | Remove the outline or add a glow |
| Fill with `primary-deep` on hover | Add a shadow, lift or scale |
