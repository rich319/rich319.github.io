The site bar: name on the left, three text links on the right.

Provide the site name and up to four lowercase links. The bar is solid `ground` with a `border-strong` underline in `primary`; it does not blur or float. The current page is `primary` with an underline; hover underlines. On phones the links wrap beneath the name.

| Do | Don't |
| --- | --- |
| Keep links to words | Use icons, avatars or a boxed call to action |
| Keep the bar the same colour as the page | Use translucency or backdrop blur |
