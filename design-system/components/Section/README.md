The repeating block of the site: a hairline rule, a mono label, a heading and copy.

Provide a one-word label, an optional heading and running text no wider than 65 characters. The rule is `border-hairline` in `rule`; space above the rule is `space-6`, below it `space-4` before the label. Inline links are `primary`, underlined 2px.

| Do | Don't |
| --- | --- |
| Left align everything | Centre headings |
| Use one label per section | Number sections or add eyebrows to the heading |
