A small square label for topic, status or year.

Provide one to three lowercase words. Outline is the default, solid marks the one live status on a page, quiet is for metadata such as a year. Status is always a word; never a coloured dot. Set in `label` with the MONO axis at 50 (semi mono). Radius is `radius-none`.

| Do | Don't |
| --- | --- |
| Keep tags to one row | Round the corners or use a pill |
| Use solid once per page | Add a second hue for status |
