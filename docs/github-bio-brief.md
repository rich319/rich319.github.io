## What he's built — the projects

### 1. HubSpot Enrichment & Onboarding Stack
Built in Relevance AI. The pipeline does automated customer research on new signups, writes enrichment data back into HubSpot, then generates 1:1 personalised onboarding emails from that data. Each email is individually crafted to the customer's context — not segmented, not templated.

**Results (60-day A/B test):**
- Open rate: 27.1% (AI) vs 17.0% (control) → **+10.1pp lift** (z=3.528, p=0.0004, significant)
- Click rate: 2.31% (AI) vs 0.41% (control) → **+1.90pp lift** (z=2.485, p=0.0129, significant)

Note: not a perfect test — control group received generic emails. But the signal is real.

---

### 2. Call Intelligence Pipeline
Ingests recordings from sales and customer success calls. Automatically surfaces feature gap requests from conversations, cross-references against Claude's knowledge base, identifies what's missing, adds it to the Linear backlog, clusters semantically similar issues, then triggers automated investigations against the codebase and competitive landscape to help with prioritisation.

Closes the loop from customer voice → prioritised engineering backlog, with minimal human handling.

---

### 3. sked-gtm — GTM Orchestration Plugin
A full go-to-market launch system built as a Claude plugin. Feed it a Linear ticket. It reads the spec, determines the right launch size (Micro → Large), then creates a fully written Notion project — every touchpoint drafted in full: email body copy, social posts, in-app guidance, help centre articles, Amplitude tracking specs, sales battle cards, audience segmentation.

Not a brief generator. Not a template filler. The actual deliverables, ready for review.

Connects: Linear, Notion, Amplitude, HubSpot, Claude in Chrome.

Repo: [github.com/DialogueConsulting/claude-code-config](https://github.com/DialogueConsulting/claude-code-config)

---

### 4. sked-adoption — Post-Launch Adoption Loop
Companion plugin to sked-gtm. Handles everything after launch: Amplitude funnel analysis to find where users drop off → targeted cohort building → in-app intervention copy → behavioural HubSpot email sequences → A/B experiment setup → fortnightly review that reads results and recommends what to iterate or close.

Together, gtm + adoption cover the full product lifecycle from announcement to sustained engagement.
